# 一、排序算法

## 1.1 冒泡排序

冒泡排序重复遍历待排序序列，每次比较相邻两个元素，若顺序错误则交换。每一轮结束后，未排序部分的最大元素会"冒泡"到末尾，因此第 i 轮之后末尾 i 个元素已经就位。

时间复杂度：最好情况 O(n)（序列已有序且加了提前退出标记），平均与最坏情况均为 O(n²)。空间复杂度 O(1)，属于稳定排序。

## 1.2 快速排序

快速排序选取一个基准元素（pivot），把序列划分成小于基准和大于基准两部分，再对两部分递归排序。划分过程使用双指针从两端向中间扫描，平均时间复杂度 O(n log n)，最坏情况退化为 O(n²)（每次选到最小或最大元素作基准）。

快速排序是原地排序，空间复杂度 O(log n)（递归栈），但属于不稳定排序。优化手段包括：随机选基准、三数取中、小区间改用插入排序。

## 1.3 归并排序

归并排序把序列二分成两半，分别排序后合并。合并时用两个指针比较两段的首元素，把较小者放入结果数组。

时间复杂度稳定在 O(n log n)，不受输入分布影响；需要 O(n) 额外空间，属于稳定排序，适合外部排序和链表排序。

# 二、查找算法

## 2.1 二分查找

二分查找要求序列有序。每次取中间元素与目标比较，相等则返回，目标较小则收缩右边界，较大则收缩左边界。

时间复杂度 O(log n)，空间复杂度 O(1)（迭代写法）。常见错误是边界更新写成 left = mid 导致死循环，正确写法应保证区间每次收缩：left = mid + 1 或 right = mid - 1。

## 2.2 哈希查找

哈希查找通过哈希函数把关键字映射到桶下标，平均时间复杂度 O(1)。冲突处理主要有链地址法和开放定址法。装填因子越大冲突越多，通常超过 0.75 就考虑扩容。

# 三、复杂度对比

| 算法 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 冒泡排序 | O(n²) | O(n²) | O(1) | 稳定 |
| 快速排序 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 归并排序 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 二分查找 | O(log n) | O(log n) | O(1) | — |
| 哈希查找 | O(1) | O(n) | O(n) | — |
